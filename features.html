核心特性

性能、安全、协议合规、跨平台 —— 四大维度支撑 Zenith 作为生产级数据面框架的底气。

性能

热路径零堆分配，极致吞吐

零拷贝

AF_XDP 数据面

XSK + UMEM + 四环，网卡驱动层旁路用户态，配合 io_uring 批量 IO（32 recv + 64 send slot，每批 ≤2 syscall）。

零分配

固定容量数组

热路径以固定容量数组替代 String/Vec，配合 SmallVec + FxHashMap，单线程本地存储无锁访问。

零成本

编译期分发

编译期 Trie 路由实现运行期零开销分发；缓存命中 body 以 Arc<[u8]> 实现 O(1) 克隆。

应用层安全

WAF 到指纹，纵深防御

WAF

6 类攻击检测

SQLi / XSS / SSRF / 命令注入 / 路径穿越 / BotThreat，50ms 预算 fail-closed，解码后就地压缩 NULL 字节防注入绕过。

指纹

JA3/JA4 阻断

TLS 与 HTTP/3(QUIC) 连接均采集指纹，blocklist 前缀阻断 + 64 分片速率限制，黑名单 403。
