核心能力

一套数据面，六种开箱即用的形态

从网卡驱动层的线速过滤，到应用层的业务路由，Zenith 把传统需要多套系统拼装的场景收敛进单一代码库。

架构分层

L2 → L7，单一代码库的完整协议栈

每一层都是可独立启用的 crate，按需引入，避免拖入不必要的重依赖。

L7应用层路由 / 中间件 / WAF / 缓存 / 代理 / 指纹决策zenith-web · waf · cache · proxy · fingerprint

L4传输层TCP 状态机 · UDP 会话表 · 端口过滤 · 转发zenith-net · forward
L3网络层IPv4/IPv6 解析 · IP 黑白名单 · CIDR 子网zenith-net · forward
